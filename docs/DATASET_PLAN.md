# Dataset Plan

## Objective

Create a balanced image dataset for training an Azure Custom Vision classification model.

## Vehicle Categories

- SUV
- Sedan
- Hatchback
- Wagon
- Ute
- Van
- Coupe
- Convertible

## Dataset Size

- 50 images per category
- Total: 400 images

## Collection Guidelines

Images should include:

- Different manufacturers
- Different colours
- Multiple viewing angles
- Various lighting conditions
- Different backgrounds

## Folder Structure

training-data/

- SUV/
- Sedan/
- Hatchback/
- Wagon/
- Ute/
- Van/
- Coupe/
- Convertible/

## Future Improvements

- Increase images to 100–150 per category.
- Include more difficult examples.
- Add more side and rear views.
